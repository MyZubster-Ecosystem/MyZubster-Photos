# MyZubster Photo Publication Policy

## Public-only repository

This repository contains only images approved for public distribution.

## Before publication

Each image should be checked for:

- EXIF metadata
- embedded GPS coordinates
- faces or personal information
- vehicle plates or identifying details where relevant
- sensitive infrastructure
- restricted/private locations
- confidential bounty evidence

## Raw uploads

Raw application uploads must not be copied here automatically.

A separate review/sanitization step is required before publication.

## Integrity

Published images should eventually have:

- stable id
- filename
- MIME type
- byte size
- SHA-256
- source category
- publication status
- optional IPFS CID

## Rewards

An image being present in this repository does not mean that a bounty has been verified or that MYZ/XMR/token settlement occurred.
